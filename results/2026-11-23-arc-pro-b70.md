| | |
|---|---|
| GPU | Intel Arc Pro B70 (Battlemage BMG-G31, PCI 0xe223), 32 GB GDDR6, `xe` kernel driver, GT0 at 2800 MHz |
| Host | 16 CPU threads, 30 GB RAM, Linux 7.0.0, Mesa 26.0.8 (ANV) |

### Decode profile (`GGML_VK_PERF_LOGGER=1`, one steady-state token)

GPU time per token **50.5 ms** (~20 t/s, GPU-bound, not CPU/launch-bound on the host side),
**6,646 dispatches** per token (7.6 µs average).

| Op | Calls | ms | Share |
|---|---|---|---|
| MUL_MAT_VEC q8_0 (attention + output head) | 289 | 13.45 | 26.6% |
| MUL_MAT_ID_VEC nvfp4 (experts) | 44 | 5.07 | 10.0% |
| MUL_MAT_VEC f32 (loop controllers, router) | 576 | 3.71 | 7.3% |
| MUL_MAT_ID_MUL fused nvfp4 | 44 | 3.23 | 6.4% |
| MUL / SCALE / CONCAT / ADD / RMS_NORM / … | ~3,000 | ~15 | ~30% |

The looped layers (6–17 run 3×) re-read their weights on every pass, so the Q8_0 attention path moves
~2.1 GB per token (~160 GB/s, ~26 % of the card's bandwidth).

## Speculative decoding (DSpark drafter, server, temp 1.0, 600 tokens)

| Prompt | no draft | DSpark `--spec-draft-n-max 2` | accepted |
|---|---|---|---|
| code | 19.7 t/s | 18.9 t/s | 295/608 (49 %) |
| prose | 19.7 t/s | 12.8 t/s | 144/907 (16 %) |

Slower on this card: verifying several tokens routes each one to its own 8 experts, multiplying expert
weight reads, and acceptance is low at the recommended temperature of 1.0.

## Memory and maximum context (Vulkan, 1 slot)

Measured VRAM (DRM fdinfo `drm-total-vram0`):

| Config | VRAM |
|---|---|
| 256K ctx, KV q8_0, 4 slots, ub 512 | 22.2 GiB |
| **384K ctx, KV q8_0, 1 slot, ub 512** | **29.1 GiB** (works) |
| 640K ctx, KV q8_0, ub 1024 | OOM: 15.5 GB compute buffer |

The compute buffer grows with *context × ubatch* (~23 bytes per element, from the relative-attention
intermediates), on top of the KV cache (~17 KiB/token at q8_0, only 8 of 48 layer passes are global).

## End-to-end (server, OpenAI API)

- Generation: 19.7 t/s (384K ctx server).
- Prefill through the server: ~400 t/s at 6K tokens, ~320 t/s at 24K tokens.
- Needle retrieval at 24K: correct. Tool calling (`tool_calls` with JSON args): correct.
